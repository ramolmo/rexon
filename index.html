Google Drive Cloud Connect (গুগল ড্রাইভ স্টোরেজ কানেক্ট)

আপনার নিজস্ব গুগল অ্যাকাউন্টের ১৫ জিবি (15 GB) ফ্রি ড্রাইভ স্টোরেজ সরাসরি এই পোর্টালের সাথে যুক্ত করুন।

📂 Open Google Drive ↗

💡 আপনার গুগল ক্লাউড কনসোল থেকে তৈরি করা Client ID এখানে একবার দিলেই হবে (ব্রাউজারে সেভ থাকবে)।

📖 কীভাবে Google Client ID পাবেন? (২ মিনিটের সহজ গাইড)

১. Google Cloud Console ↗ এ গিয়ে একটি নতুন প্রজেক্ট তৈরি করুন।

২. APIs & Services ➔ Library থেকে Google Drive API সার্চ করে Enable করুন।

৩. Credentials ➔ Create Credentials ➔ OAuth client ID বেছে নিন (Application type: Web application)।

৪. Authorized JavaScript origins-এ আপনার বর্তমান ওয়েবসাইটের লিংক (যেমন: https://yourname.github.io) যোগ করে Create চাপুন।

৫. তৈরি হওয়া Client ID টি কপি করে উপরের বক্সে পেস্ট করে Connect Google Drive বাটনে ক্লিক করুন।

☁️ সুপাবেস ছাড়াও ফ্রিতে আনলিমিটেড / বাড়তি স্টোরেজ পাওয়ার সেরা উপায়সমূহ

🔥
১. Google Firebase Firestore
1 GB সম্পূর্ণ ফ্রি
  • সুপাবেসের দ্বিগুণ (1 GB) ফ্রি ক্লাউড স্টোরেজ।
  • কখনো স্লিপ বা পজ (Pause) হয় না।
  • গুগলের নিজস্ব নিরাপদ ক্লাউড ডাটাবেজ।
  • Firebase Console থেকে ৫ মিনিটে ফ্রি প্রজেক্ট খোলা যায়।
⚡
২. Cloudflare D1 + R2
5 GB থেকে 10 GB ফ্রি
  • Cloudflare D1-এ ৫ জিবি SQL ডাটাবেজ ফ্রি।
  • Cloudflare R2-তে প্রতি মাসে ১০ জিবি ফাইল স্টোরেজ ফ্রি।
  • বিশ্বের সবচেয়ে ফাস্ট ক্লাউড নেটওয়ার্ক।
  • Cloudflare ড্যাশবোর্ড থেকে সহজেই ব্যবহার করা যায়।
📁
৩. Google Drive Cloud Archiving
15 GB প্রতি জিমেইলে ফ্রি
  • কোনো নতুন অ্যাকাউন্ট খোলা ছাড়াই আপনার জিমেইলে ১৫ জিবি ফ্রি।
  • প্রতি মাস শেষে ১-ক্লিকে এক্সেল বা JSON ব্যাকআপ গুগল ড্রাইভে আপলোড করে রাখুন।
  • সুপাবেস ডাটাবেজ সব সময় খালি, ফ্রেশ ও ফাস্ট থাকবে।
